# PUTERA MY — Portfolio

A professional portfolio for Putera, a Computer Technology (Cloud Computing) student focused on front-end development, cloud and IT support.

Built with Next.js 16 App Router, TypeScript, Tailwind CSS 3.4, framer-motion, next-themes and lucide-react.

## Setup

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

## Before applying for jobs

Add a real email, LinkedIn profile, CV and project screenshots. Placeholder links are automatically disabled in the interface.

See `data/site.ts` and `data/projects.ts`.
