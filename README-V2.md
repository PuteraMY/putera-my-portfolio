# PUTERA MY V2
Preview-only candidate. The existing live portfolio on main is unchanged.
## Stack
Next.js 16 App Router, TypeScript, Tailwind v3.4, Framer Motion, next-themes, Lucide, next/font, next/image, next/og. No backend or database.
## Commands
npm install
npm run typecheck
npm run build
npm run dev
## Data model
Edit data/site.ts for profile, availability, CV and socials. Add ONE new record to data/projects.ts to create project cards, case studies, command navigation, OG images and sitemap entries. Add optional screenshots in public/projects/<slug>/; omit the images field data when no verified screenshot.
## Placeholders
Email, LinkedIn, CV, profile picture, project case-study details and dates, real screenshots, skill proficiency tags and availability.
## Design
Exact palette: cream #FFF9EE, ink #14110F, cobalt #2447FF, yellow #FFD23F and coral #FF6B4A. No gradients or glowing blobs. Reduced-motion respected.
