# Midnight Blue Editorial — design review

This branch is a **visual preview only**. Production continues to use `main`.

Color direction:
- Midnight Navy `#142638`
- Soft Ivory `#F7F7F4`
- Steel Blue `#367EA5`
- Warm Copper `#D5A16C`

The redesigned experience changes the hero hierarchy, portfolio visual identity, featured-project presentation, skills layout, profile and contact treatment. No changes are made to project data, CV placeholders or deployment settings.

The approved Concept F logo is not yet supplied as a production-ready asset. This preview uses the existing temporary geometric mark recolored for the navy palette.

To publish after approval, merge this branch into `main`. Until then, do not promote the preview deployment to production.
